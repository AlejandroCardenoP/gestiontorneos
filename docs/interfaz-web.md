# Interfaz web independiente

La interfaz CANCHA se mantiene en el proyecto separado `gestiontorneos-frontend`.
La versión anterior estaba incorporada al JAR; ya no se empaqueta dentro del backend.

Consultar [la guía de separación](frontend-separado.md) para la configuración y el
orden de despliegue. Los archivos y las instrucciones de la interfaz están en el
README del repositorio frontend.
